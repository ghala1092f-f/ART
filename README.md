# ART — ARTI 303 Lab 3

This folder contains the completed `lab03.ipynb` for Lab 3.

Project structure created by the lab:
- `src/` — reusable Python modules
- `tests/` — automated tests
- `data/` — input files
- `logs/` — generated output (ignored by Git)
- `requirements.txt` — dependencies
- `.gitignore` — files that should not be committed

## GitHub
Open a terminal inside this `ART` folder and run:

```bash
git init

git commit -m "Complete Lab 3"
git branch -M main
git remote add origin <YOUR-GITHUB-REPOSITORY-URL>
git push -u origin main
```

Do not upload `.venv/`, credentials, or generated logs.
